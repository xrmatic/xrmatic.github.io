# Support for Color Finder Plus

Thank you for using Color Finder Plus. We are committed to providing a fast, practical, and privacy-conscious color inspection experience for Chromium-based browsers.

If you have questions, run into issues, or would like to suggest a feature, please reach out.

## Contact Information

For all inquiries, please use the support contact listed in the extension store listing or on the project's public support page.

* * *

## How can we help?

### Issues & Bug Reports

If something is not working as expected, please include the following in your message to help with troubleshooting:

- Your browser and version number
- Whether you are using Chrome, Microsoft Edge, or another Chromium-based browser
- A short description of the steps to reproduce the issue
- Any visible error messages
- Whether the issue happens with `Start Picker`, `Draw Selection Box`, the side panel, or the Options page

### Feature Requests

Have an idea to make Color Finder Plus better? Whether it is a workflow improvement, a side panel enhancement, a picker adjustment, or a palette feature, feedback is welcome.

### General Questions

If you are unsure how the picker zoom, side panel density, font sizes, or selection behavior work, check the extension Options page first. If you still need help, send a support message with the question and the browser you are using.

* * *

## Privacy & Security Reminder

As documented in the [Privacy Policy](../privacy/privacy-policy.md), Color Finder Plus does not collect or transmit your browsing data, screenshots, or color selections to the developer or to third parties. Visible page imagery is processed locally in your browser to identify colors, and settings are stored locally using `chrome.storage.local`.

If you contact support, please do not include sensitive personal information, account data, or screenshots containing private content unless you are comfortable sharing them.
